== `1.3.0` (in development)

=== Release
- https://github.com/peopleware/net-ppwcode-vernacular-contracts/tree/I/1.3.0-alpha.28[GitHub]
- https://www.nuget.org/packages/PPWCode.Vernacular.Contracts.I/1.3.0-alpha.28[NuGet]

=== Changes
- Add support for .NET 9.0 & 10.0
- Remove support for .NET 6.0 (fallback to .net standard 2.0 and JetBrains annotations)
- Build and publish workflows on GitHub actions
- Upgraded dependencies
