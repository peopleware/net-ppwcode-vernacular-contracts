
# Changelog PPWCode.Vernacular.Contracts.I

## [1.3.0](https://github.com/peopleware/net-ppwcode-vernacular-contracts/tree/I/1.3.0)

- Add support for .NET 9.0 & 10.0
- Remove support for out-of-support .NET 6.0 (fallback to .net standard 2.0 and
  JetBrains annotations)
- Build and publish workflows on GitHub actions
- Upgraded dependencies

## [1.2.0](https://github.com/peopleware/net-ppwcode-vernacular-contracts/tree/I/1.2.0)

- Add support for Microsoft nullability attributes (in .NET Core builds, .NET
  Framework builds use JetBrains.Annotations attributes)

## [1.1.0](https://github.com/peopleware/net-ppwcode-vernacular-contracts/tree/1.1.0)

- Target .net standard 2.0
- Upgraded dependencies

## [1.0.0](https://github.com/peopleware/net-ppwcode-vernacular-contracts/tree/1.0.0)

- Initial release of the library
